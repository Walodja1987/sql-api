Step 01

Install SQL Server Express

SQL Server Express is Microsoft's free edition. Use it to run a real SQL database on your own Windows computer.

  1. Open the official SQL Server downloads page.
  2. Find the Express edition of SQL Server 2025 and download the installer.
  3. Run the installer and choose Basic for the simplest local setup.
  4. Complete installation and note the instance name. The default Express instance name is typically SQLEXPRESS.
  5. Look for “Installation has completed successfully!” before closing the installer.
Typical local server name
localhost\SQLEXPRESS
Check your actual instance name

If your installation shows a different instance name, use that name instead of SQLEXPRESS in the remaining steps.

Optional: Verify the Windows service

  1. Press Win + R, type services.msc, and press Enter.
  2. Find SQL Server (SQLEXPRESS).
  3. Confirm that its status is Running. Start the service if it is stopped.
Step 02

Install SSMS

SQL Server Management Studio (SSMS) is the graphical tool for connecting to SQL Server, executing queries, creating databases, and inspecting tables.

  1. From the SQL Server installer, click Install SSMS; alternatively, open the official SSMS installation guide.
  2. Download and run the SSMS 22 installer. SSMS 22 uses Visual Studio Installer for installation and updates.
  3. Follow the prompts and install with the default components.
  4. After installation, find SQL Server Management Studio 22 in the Start menu and launch it.
Good to know

You can close both installation windows once SQL Server Express and SSMS have been installed successfully. Closing them does not stop the SQL Server service.

Step 07 · Completed

Enable SQL Server TCP/IP access

SSMS can access a local SQL Server without proving that network clients can connect. Enable TCP/IP so an Ubuntu process can reach the SQL Server instance through a specific port.

1. Enable TCP/IP and set a fixed port
  1. Open SQL Server 2025 Configuration Manager on Windows.
  2. Navigate to SQL Server Network Configuration → Protocols for SQLEXPRESS.
  3. Right-click TCP/IP → Enable, if it is disabled.
  4. Open TCP/IP → Properties → IP Addresses.
  5. Under IPAll, clear the TCP Dynamic Ports field and enter 1433 in TCP Port (assuming the port is available).
  6. Apply the changes.

If Listen All is set to Yes on the Protocol tab, the IPAll port settings apply. Otherwise, review the enabled individual IP entries as well.

2. Restart the SQL Server service
  1. In Configuration Manager, open SQL Server Services.
  2. Find SQL Server (SQLEXPRESS).
  3. Right-click → Restart.
  4. Verify its status returns to Running.

Alternative: restart SQL Server (SQLEXPRESS) from services.msc.

Use a deliberate port and network scope

Port 1433 is an example, not a requirement. Make sure it is available. For workplace deployment, agree on the port, listeners and network access with IT; avoid exposing the service to the public internet.

Step 09 · Completed

Allow only WSL through Windows Firewall

If Windows connects to SQL Server but WSL times out, Windows Firewall may be blocking the inbound connection. In our test, adding a restricted inbound rule resolved the timeout.

1. Open an elevated PowerShell terminal
  1. Open the Windows Start menu and search for PowerShell.
  2. Choose Run as administrator (German: Als Administrator ausführen).
  3. Approve the elevation prompt. The window title should begin with Administrator:.
  4. Use hostname -I in Ubuntu to find the WSL address to allow.
2. Create the scoped firewall rule

Replace <WSL_IP> with the actual WSL IP. Run the command in Administrator PowerShell:

PowerShell · administrator
PowerShell · administrator
New-NetFirewallRule `
  -DisplayName "SQL Server Express - WSL" `
  -Direction Inbound `
  -Protocol TCP `
  -LocalPort 1433 `
  -RemoteAddress <WSL_IP> `
  -Action Allow `
  -Profile Any

This is restricted by remote IP and port; it is not a general-purpose SQL Server access rule. WSL IPs can change on restart, in which case the rule might need updating. Use a firewall profile/scope appropriate to your own environment.

3. Confirm and retest
Ubuntu shell
Ubuntu shell
nc -vz -w 3 <WINDOWS_HOST_IP> 1433

A successful response includes succeeded!. You do not need to restart SQL Server just to add the firewall rule.

Security boundary

Only use this change on a machine you administer and with appropriate authorization. In production, IT should decide which Ubuntu server is permitted to reach SQL Server, enforce network restrictions, and choose an authentication method and account with minimal required database privileges. Do not reuse an ephemeral WSL firewall rule as a production policy.

2. Replace server.py with the tested CRUD implementation

~/github/sql-api/server.py · Python 3.12
import os

from dotenv import load_dotenv
from fastapi import FastAPI, HTTPException, Response
from pydantic import BaseModel, Field
from mssql_python import connect

load_dotenv()
app = FastAPI(title="SQL API", version="1.1.0")


def get_connection():
    return connect(os.environ["SQL_CONNECTION_STRING"])


class CustomerInput(BaseModel):
    FirstName: str = Field(min_length=1, max_length=100)
    LastName: str = Field(min_length=1, max_length=100)
    Email: str | None = Field(default=None, max_length=255)


def customer_to_dict(row):
    return {
        "CustomerId": row[0],
        "FirstName": row[1],
        "LastName": row[2],
        "Email": row[3],
    }


@app.get("/")
def home():
    return {"message": "SQL API is running"}


@app.get("/api/customers")
def get_customers():
    with get_connection() as conn:
        cursor = conn.cursor()
        cursor.execute("""
            SELECT CustomerId, FirstName, LastName, Email
            FROM dbo.Customers
            ORDER BY CustomerId
        """)
        return [customer_to_dict(row) for row in cursor.fetchall()]


@app.post("/api/customers", status_code=201)
def create_customer(customer: CustomerInput):
    with get_connection() as conn:
        cursor = conn.cursor()
        cursor.execute("""
            INSERT INTO dbo.Customers (FirstName, LastName, Email)
            OUTPUT INSERTED.CustomerId, INSERTED.FirstName,
                   INSERTED.LastName, INSERTED.Email
            VALUES (?, ?, ?)
        """, (customer.FirstName, customer.LastName, customer.Email))
        row = cursor.fetchone()
        result = customer_to_dict(row)
        conn.commit()
        return result


@app.put("/api/customers/{customer_id}")
def update_customer(customer_id: int, customer: CustomerInput):
    with get_connection() as conn:
        cursor = conn.cursor()
        cursor.execute("""
            UPDATE dbo.Customers
            SET FirstName = ?, LastName = ?, Email = ?
            OUTPUT INSERTED.CustomerId, INSERTED.FirstName,
                   INSERTED.LastName, INSERTED.Email
            WHERE CustomerId = ?
        """, (
            customer.FirstName,
            customer.LastName,
            customer.Email,
            customer_id,
        ))
        row = cursor.fetchone()
        if row is None:
            raise HTTPException(status_code=404, detail="Customer not found")
        result = customer_to_dict(row)
        conn.commit()
        return result


@app.delete("/api/customers/{customer_id}", status_code=204)
def delete_customer(customer_id: int):
    with get_connection() as conn:
        cursor = conn.cursor()
        cursor.execute("""
            DELETE FROM dbo.Customers
            OUTPUT DELETED.CustomerId
            WHERE CustomerId = ?
        """, (customer_id,))
        row = cursor.fetchone()
        if row is None:
            raise HTTPException(status_code=404, detail="Customer not found")
        conn.commit()
    return Response(status_code=204)
Development-only API

These write endpoints have no application-layer authentication. Keep Uvicorn bound to 127.0.0.1 and do not expose the API on a company network or public interface. For production, add authentication, authorization, proper TLS, safe secret handling, and operational controls.

Where are the status codes in /docs?

After clicking Execute, scroll to Server response. The Code column displays the actual result (for example 201). The lower Responses section lists possible documented responses, such as 201 and 422; it is not the executed result.

In our test, the POST response showed 201 and returned a customer object. The generated example schema displayed "string" because we had not yet added an explicit FastAPI response model. Response-model improvements are postponed until the generic API design.

What does PUT mean here?

PUT replaces all editable fields of the customer record. The Email field is optional in the model, so omitting it during PUT sets it to SQL NULL. An endpoint supporting partial updates could be added later with PATCH.

Reference · side note

What is a Python virtual environment?

Why create a separate environment for every project?

A Python virtual environment provides an isolated Python executable and package installation area for a project. Different projects can use different dependency versions without installing those dependencies system-wide.

It is not a separate operating system, virtual machine, or container. It generally uses a Python interpreter derived from the installed system version.

Can .venv have another name?

Yes. .venv, venv or myenv are all valid folder names. .venv is a widely recognized convention; its leading dot hides it in Linux file listings by default.

Ubuntu · create environment
Ubuntu · create environment
python3 -m venv .venv
# Or: python3 -m venv myenv
Why activate it? Is activation required?

source .venv/bin/activate adjusts your shell's PATH so that python and pip point to the project's environment. The setting applies to your current shell session. Activation is convenient, not mandatory:

# Equivalent without activation:
.venv/bin/python -m uvicorn server:app --port 8000

For production service definitions, specifying the environment's interpreter path directly is often clearer.

Tips & troubleshooting

How do I change SSMS from German to English?

SSMS 22 is installed using Visual Studio Installer. Its default language commonly follows your Windows language. To add English:

  1. Close SSMS.
  2. Open Visual Studio Installer.
  3. Find SQL Server Management Studio 22 and click Modify (German: Ändern).
  4. Open Language packs (German: Sprachpakete), select English, and apply the change.
  5. Restart SSMS. If the interface is still German, open Extras → Optionen → Umgebung → Internationale Einstellungen, select English if available, and restart again.

Official documentation: Modify SSMS language packs.

Does SQL Server stop when I close SSMS?

No. SQL Server Express runs as a Windows service. SSMS is only the administration interface. You can close SSMS without stopping the database engine.

I cannot connect to localhost\SQLEXPRESS
  1. Confirm the instance name shown by the SQL Server installer.
  2. Open services.msc and check SQL Server (SQLEXPRESS) is running.
  3. In SSMS, use Windows Authentication and the correct server name.
  4. For a local certificate validation error, try Trust server certificate in the connection dialog. Do not use this as a production security default.
Why is my new database or table missing in Object Explorer?

Right-click the Databases or Tables folder and select Refresh (German: Aktualisieren). Ensure your query was executed against the intended server and database.

Do I need to install Python to use SQL Server?

No. SQL Server and SSMS work independently of Python. For the current Ubuntu/WSL workflow, Python is installed only in Ubuntu; SQL Server runs on Windows. A separate C# bridge remains a future alternative.

Ubuntu / WSL connection times out

First confirm SQL Server is listening on the configured TCP port and that Windows can connect using Test-NetConnection. Next verify WSL's Windows gateway using ip route show default. If local Windows connectivity succeeds but WSL times out, inspect firewall restrictions and WSL's networking mode. Use nc -vz -w 3 so the test does not hang indefinitely.

PowerShell shows “Zugriff verweigert” / Access Denied

New-NetFirewallRule requires administrator privileges. Reopen PowerShell using Run as administrator before retrying. Do not weaken the firewall globally to make the test pass.

Will my WSL IP stay the same?

Not necessarily. WSL2 in NAT mode can receive a different address when restarted, which can invalidate an IP-restricted firewall rule. Re-check with hostname -I if connectivity suddenly stops working.

Appendix B

Troubleshooting & lessons learned

These are real problems encountered while building this lab. Treat the checks as diagnostics, not a checklist of changes that every system requires. Keep WSL-specific remedies out of normal Ubuntu production deployments.

SQL Server port 1433 times out from Ubuntu

Symptom: nc -vz -w 3 <HOST> 1433 times out even when SSMS works locally. Why: TCP/IP might be disabled, the target IP might be wrong, or a firewall could be blocking WSL traffic. Verify the SQL Server listening socket and local Windows connectivity before changing firewall rules.

Windows PowerShell
Windows PowerShell
Get-NetTCPConnection -LocalPort 1433 -State Listen
Test-NetConnection -ComputerName 127.0.0.1 -Port 1433
Ubuntu WSL
Ubuntu WSL
ip route show default
hostname -I
nc -vz -w 3 <WINDOWS_HOST_IP> 1433

The lab connection succeeded after adding an inbound TCP rule restricted to the WSL IP. Do not expose SQL Server broadly or assume WSL IPs are permanent.

New-NetFirewallRule shows Access Denied

Cause: PowerShell was not elevated. Open PowerShell with Run as administrator and execute the narrowly scoped rule described in Step 09. Do not disable Windows Firewall to bypass the error.

Python 3.8 cannot install mssql-python

Symptom: No matching distribution found for mssql-python on Ubuntu 20.04 / Python 3.8. Lesson: Check the driver's supported Python versions and native Linux requirements before installing. Updating only the Python interpreter on an old Ubuntu version may still leave incompatible runtime libraries. For this lab the clean solution was a separate Ubuntu 24.04 WSL distribution.

Ubuntu 20.04 does not offer python3.12-venv

Symptom: Unable to locate package python3.12 and python3.12-venv. A similarly named PostgreSQL extension package was present, but it was not the Python interpreter. The team switched to Ubuntu 24.04 instead of forcing an unsupported upgrade path.

Windows executables fail with Exec format error in WSL

Symptom: Both notepad.exe and cursor . failed; /proc/sys/fs/binfmt_misc/WSLInterop did not exist. The recorded workaround was to prevent systemd-binfmt from interfering with WSL's executable registration:

Ubuntu 24.04 · opens editor
Ubuntu 24.04 · opens editor
sudo systemctl edit systemd-binfmt.service

Place the following in the editable upper portion of the editor, above the comment indicating that edits below will be discarded:

systemd override
systemd override
[Unit]
ConditionVirtualization=!wsl
Ubuntu · after saving override
Ubuntu · after saving override
sudo systemctl daemon-reload

Then run wsl --shutdown in Windows PowerShell and relaunch Ubuntu; test notepad.exe and cursor .. This workaround resolved the issue in this lab; apply only when the symptom and diagnosis match, not as a default on ordinary Ubuntu machines.

Cursor reports terminal sandbox needs kernel 6.2+

Symptom: Cursor's AI terminal sandbox reported that WSL kernel 5.15 was too old. The API itself could run, but agent sandboxing could not use the required kernel features. Running wsl --update, then wsl --shutdown, upgraded this lab to WSL 3.0.5.0 and kernel 6.18.58.1. Verify using wsl --version on Windows and uname -r inside Ubuntu.

Cursor cannot create .env: EACCES

Symptom: A cloned project's directory belonged to root. Fix: confirm ownership with ls -ld ~/github/sql-api and, only for your own project folder, restore ownership:

Ubuntu · use only for your own project
Ubuntu · use only for your own project
sudo chown -R "$(whoami):$(id -gn)" ~/github/sql-api

Do not recursively change ownership of unrelated system or shared directories.

.venv/bin/activate is missing

Cause: The virtual environment is intentionally ignored by Git, so a fresh clone will not contain it. Create a new environment with python3 -m venv .venv, activate it, then install requirements.

ModuleNotFoundError: dotenv

Cause: python-dotenv was absent from the active environment. Run python -m pip install python-dotenv after activating the correct venv, then test import dotenv.

API root works but /api/customers fails

A working root endpoint confirms FastAPI, not SQL authentication. Recheck the .env connection string, current Windows host IP, read permissions for the SQL login, and SQL Server network access. Avoid sharing connection strings with passwords in screenshots or logs.

mssql-python imports, but connection raises DDBC Error: Failed to load the driver

Observed: from mssql_python import connect worked, but GET /api/customers returned HTTP 500. The traceback ended with OperationalError: DDBC Error: Failed to load the driver. This indicates a failure loading native Linux driver dependencies, not necessarily invalid SQL credentials.

Verified resolution on Ubuntu 24.04: install the missing libraries, then restart FastAPI.

Ubuntu · Bash
Ubuntu · Bash
sudo apt update
sudo apt install -y libltdl7 libkrb5-3 libgssapi-krb5-2

After installing these packages, /api/customers successfully returned records from SQL Server. The browser's /favicon.ico 404 log entry is unrelated and harmless for this API-only tutorial.

POST / PUT / DELETE fails with SQL permissions error

Creating sqlapi with db_datareader is sufficient for GET only. Run the GRANT INSERT, UPDATE, DELETE ON OBJECT::dbo.Customers TO sqlapi script in Step 12 for the local lab. Do not grant db_owner or broad database write privileges simply to fix a CRUD test.
